Справочник для модуля нормоконтроля. Значения извлечены **дословно** из
[СП 124.13330.2012 «Тепловые сети»](https://nostroy.ru/nostroy_archive/nostroy/898581711-SP%20124.13330.2012(dlya%20oznakomleniya).pdf),

## А.3. Расстояния по горизонтали (подземная прокладка)

Наименьшие расстояния в свету от строительных конструкций тепловых сетей или
оболочки изоляции при бесканальной прокладке.

| Условия | Ду, мм | Расстояние, м |
|---|---|---|
| В каналах и тоннелях, непросадочные грунты (от наружной стенки канала) | < 500 | **2,0** |
| | 500–800 | **5,0** |
| | ≥ 900 | **8,0** |
| То же, просадочные грунты I типа | < 500 | **5,0** |
| | ≥ 500 | **8,0** |
| Бесканальная прокладка, непросадочные грунты (от оболочки) | < 500 | **5,0** |
| | 500–800 | **7,0** |
| | ≥ 800 | **9,0** |
| То же, просадочные грунты I типа | ≤ 100 | **5,0** |
| | > 100 и < 500 | **7,0** |

### Надземная прокладка — до жилых и общественных зданий

Водяные тепловые сети, паропроводы Ру ≤ 0,63 МПа, конденсатные сети:

| Ду, мм | Расстояние, м |
|---|---|
| 500–1400 | **25** |
| 200–500 | **20** |
| < 200 | **10** |

Также: до бортового камня / бровки кювета — **0,5 м**; до ствола дерева — **2,0 м**;
до сооружения земляного полотна ж/д — **3 м**; до оси трамвайного пути — **2,8 м**;
до сетей ГВС — **5 м**.

## Оговорки, важные для реализации

1. **Расстояния можно уменьшать** в стеснённых условиях при выполнении защитных
   мероприятий (Приложение Д, таблица Д.2 СП 124.13330; для СП 42.13330 —
   футляры, обоймы, усиленная гидроизоляция). Значит, нарушение норматива —
   не всегда «нельзя», иногда «дороже». В модели это отдельный флаг: жёсткий
   запрет либо надбавка на защитные мероприятия.
2. **Буфер зависит от Ду и способа прокладки** — например, до фундамента 2,0 м при
   канальной прокладке и 5,0 м при бесканальной для одного и того же Ду < 500.
   Поэтому запретные зоны строятся уже после предварительного подбора диаметра.
3. **Просадочные грунты I типа** увеличивают отступы почти вдвое — параметр района,
   а не трассы. В демо оставляем переключатель: видно, как трасса меняется.
4. СП 42.13330.2016 (таблицы 12.5, 12.6) для тепловых сетей **отсылает к
   СП 124.13330** — поэтому основным источником берём именно его.
